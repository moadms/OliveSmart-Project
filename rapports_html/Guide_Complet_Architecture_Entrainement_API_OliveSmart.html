4. Filtrage G?om?trique Spatial (Ray-Casting Jordan)

Pour garantir qu'aucun olivier ext?rieur ? la parcelle trac?e par le professeur ne soit comptabilis?, le service Java impl?mente l'algorithme du Ray-Casting bas? sur le th?or?me de la courbe de Jordan :

Code Java Natif dans RayCastingGeofenceService.java :
public boolean isPointInsidePolygon(double pointLat, double pointLng, List<GpsPoint> polygon) {
    boolean inside = false;
    int j = polygon.size() - 1;
    for (int i = 0; i < polygon.size(); i++) {
        GpsPoint pi = polygon.get(i);
        GpsPoint pj = polygon.get(j);

        if ((pi.lat() > pointLat) != (pj.lat() > pointLat) &&
            (pointLng < (pj.lng() - pi.lng()) * (pointLat - pi.lat()) / (pj.lat() - pi.lat()) + pi.lng())) {
            inside = !inside;
        }
        j = i;
    }
    return inside;
}
